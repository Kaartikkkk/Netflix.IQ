

Netflix.IQ is a comprehensive analytics and intelligence platform for exploring, visualizing, and deriving insights from Netflix datasets. It features a data pipeline, machine learning models, and an interactive dashboard for business and advanced analytics.

## Features

- Data cleaning, merging, and processing scripts
- Machine learning models for predictions and recommendations
- Interactive analytics dashboard (Frontend)
- Exploratory data analysis notebooks
- Modular and extensible codebase

## Project Structure

- app.py — Main application entry point
- src — Core analytics engine, data pipeline, and ML models
- Frontend — Dashboard UI (HTML, CSS, JS)
- Master_dataset_Netflix — Raw and processed datasets, scripts, and reports
- notebooks — Jupyter notebooks for EDA and prototyping
- data — Data storage (raw, processed, and artifacts)

## Getting Started

1. Clone the repository
2. Install dependencies (see requirements.txt)
3. Run the backend server:
   ```
   python app.py
   ```
4. Open the dashboard in your browser
